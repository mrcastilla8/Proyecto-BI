# SSIS: CSV a staging
Responsable Poma (`@GabrielPGu`), rama `poma/ssis-ingesta`. Ruta reservada para proyecto Visual Studio independiente; no existe `.dtsx` ni `.dtproj` falso. Instala extensión SSIS. Parametriza CSV_ROOT, base, instancia/autenticación; rutas relativas y nombres de archivo/columnas originales. Inspecciona CSV real para determinar UTF-8/BOM, separador, decimal, fechas y quoting; no asumir. Registra filas leídas/aceptadas/rechazadas y razón, lote, duración, errores y reejecución. Aceptación exige prueba Windows con fixtures y datos autorizados, conteos cotejados y captura real. No cargar datos reales a CI.

# Fixtures sintéticas
Todas las filas son ficticias, no proceden de Olist ni representan frecuencias. Las nueve fuentes válidas tienen encabezados sintéticos que siguen exactamente, en nombre y orden, el esquema provisional de `contracts/modelo-dimensional.v1.json`; no son encabezados confirmados del dataset auténtico. Incluyen pedido con varias líneas, varios pagos y reseñas, cliente recurrente (`customer_unique_id` compartido), pedido sin líneas, estado artificial desconocido, entrega tardía, fecha real nula, entrega durante el día prometido, entrega al día siguiente y multiplicidad geográfica por prefijo. `invalid_references.csv` es un caso negativo deliberadamente huérfano y permanece separado de las nueve fuentes. Las fixtures no perfilan Olist ni prueban ETL, SQL Server o idempotencia. Validar nombres y tipos definitivos contra CSV auténticos antes de fijar SSIS.

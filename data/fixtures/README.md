# Fixtures sintéticas
Todas las filas son ficticias, no proceden de Olist ni representan frecuencias. Hay muestras pequeñas de las nueve fuentes, incluido un pedido con varias líneas, varios pagos y reseñas, cliente recurrente (`customer_unique_id` compartido), pedido sin líneas, estado artificial desconocido, entrega tardía, fecha real nula y más de una geolocalización para un prefijo. `invalid_references.csv` es un caso negativo deliberadamente huérfano y debe rechazarse; no forma parte de las nueve cargas válidas. Los CSV usan nombres breves descritos por `scripts/validar_base.py`; no son perfil de Olist ni prueba de ETL, SQL Server o idempotencia. Las columnas/tipos completos de fuente siguen pendientes de cotejo contra archivos auténticos.

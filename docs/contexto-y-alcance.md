# Contexto y alcance

## Preguntas
¿Qué precio de productos entregados se observa por tiempo/categoría? ¿Cuántos pedidos con líneas entregadas hay? ¿Cómo se compara cumplimiento de promesa por fecha/estado? ¿Qué productos/vendedores concentran líneas y flete? ¿Qué calificación media por pedido se observa por geografía?

## Nivel 1
Descarga manual; nueve fuentes Olist; staging, ETL SSIS, dimensiones/hechos SQL Server, SSAS Tabular con relaciones/jerarquías/DAX, Power BI Live de cuatro páginas; controles, evidencia e informe reproducible. Tecnologías obligatorias: Visual Studio Community con extensiones SSIS/Analysis Services Projects, SQL Server, SSMS, SSIS, SSAS Tabular, Power BI Desktop, Git/GitHub. Python estándar solo para validaciones, documentación y fixtures.

Fuera del alcance: ML de riesgo logístico, tiempo real, Azure/cloud, APIs y servicios públicos; solo se listan como mejoras futuras sin scaffolding. Los CSV no han sido inspeccionados; no se afirman conteos, nulos, fechas exactas ni resultados.

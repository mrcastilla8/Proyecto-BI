# Colaboración

Ramas estables y responsables están en raíz `AGENTS.md`. Derivar de master, commits y PR en español; una aprobación humana distinta del autor, conversaciones resueltas y CI. CODEOWNERS solicita revisiones automáticamente cuando el usuario tiene escritura y la regla está habilitada; no concede permisos por carpeta ni impide ediciones. Invitación enviada no equivale a aceptada.

Contratos compartidos no cambian sin issue y ADR revisado por equipos dependientes. Si integración falla, preservar logs/lote, corregir rechazos, restaurar localmente con scripts aprobados y reejecutar para demostrar idempotencia. No compartir datos reales ni backups en Git.
